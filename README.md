# EduQuest AI

下面按“教科研智能管理与AI赋能系统”来梳理。系统定位不是替代教师做科研，而是做政策情报、选题辅助、课题全生命周期管理、过程性数据沉淀、专家指导、论文成果辅助、课堂反思数据化、科研决策分析，实现“提效、减负、创新、合规”。

一、系统定位与核心目标
系统名称建议：教科研智能管理与AI赋能平台
服务对象：教育发展与创新研究院、科研管理部门、校领导、课题负责人、教师、评审/指导专家、系统管理员
核心目标：

解决课题“重申报、轻过程”问题。

用AI辅助选题、政策分析、论文框架、格式规范、查重与AIGC检测。

通过课堂分析、教学反思、过程数据，形成可追溯科研证据链。

支撑学校五年规划、双新实验项目、国家/市/区课题落地。

建立教师科研画像、学校科研看板、立项分析与选题分析。

防止全文AI代写，保留人工创作与过程留痕。

```sh

```
